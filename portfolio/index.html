About
Sobre

End-to-end BI, from SQL to public-facing dashboards.

BI end-to-end, do SQL ao dashboard público.

For the past 4+ years, I've worked at the intersection of data engineering, business intelligence, and public sector compliance. My core stack is Power BI, DAX, and SQL Server, but I also work with Python (Pandas, NumPy, FastAPI) and WordPress for end-to-end portal delivery.

At TCDF — Brazil's Federal District Court of Accounts — I've shipped 20+ corporate dashboards used by 100+ auditors and own 10 public-facing dashboards live on the official .gov.br domain. I implemented Row-Level Security in production and apply LGPD (Brazilian GDPR) including PII masking.

On the side, I'm building a contract validation engine for IFRS17 — the international standard for insurance contracts — for a private-sector client, using Python and FastAPI.

I'm currently pursuing a B.Sc. in Data Science and looking for remote opportunities where data drives decisions.

Há mais de 4 anos atuo na interseção entre engenharia de dados, business intelligence e compliance no setor público. Meu stack principal é Power BI, DAX e SQL Server, mas também trabalho com Python (Pandas, NumPy, FastAPI) e WordPress para entregas end-to-end.

No TCDF — Tribunal de Contas do Distrito Federal — entreguei mais de 20 dashboards corporativos usados por 100+ auditores e mantenho 10 painéis públicos no domínio oficial .gov.br. Implementei Row-Level Security em produção e aplico LGPD com mascaramento de dados pessoais.

Em paralelo, desenvolvo um motor de validação contábil para IFRS17 — norma internacional para contratos de seguros — para um cliente privado, usando Python e FastAPI.

Atualmente curso Bacharelado em Ciência de Dados e busco oportunidades remotas onde dados guiam decisões.
